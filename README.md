# استوديو دقيقة — تريتمنت وستوري بورد إعلان حرير

موقع عرض تفاعلي بالعربية (RTL) لحملة سيارة شانجان والقرعة عبر تطبيق حرير. بُني من ملف
`STUDIO_MINUTE_HARIR_CHANGAN_STORYBOARD_AR.pdf`، والنصوص منقولة منه حرفياً.

## ما في الصفحة

- **انترو 2.8ث** على أحمر دقيقة `#990B0B`: فتحة العدسة (مقتطعة من ملف الشعار نفسه، غير مُعاد رسمها) تتحرك خلفه، ثم يظهر الشعار ويثبت ويكشف عنوان المشروع. فيه زر «تخطي الانترو» (ومفتاح Esc)، ولا يظهر أبداً مع إعداد Reduce Motion. يظهر مرة واحدة في كل جلسة تصفح، ويمكن إعادته من أسفل الصفحة.
- الفكرة، الأسلوب الإخراجي، المعالجة البصرية والصوتية، الشخصيات والاستمرارية، **خريطة الملابس** (مع تمييز أدوار كل مؤدية وروابط للقطات التي تتكلم فيها)، **مرجع القاعة**، اللوحة المرجعية.
- **تقسيم الفيلم** + **معاينة الإيقاع**: تعرض اللقطات بمددها التقديرية مع الحوار كترجمة، وخط زمني قابل للنقر للقطات الـ29.
- **الستوري بورد التنفيذي**: 29 بطاقة. لكل لقطة رقمها ومدتها وصورتها المستقلة القابلة للتكبير، والكادر والعدسة والحوار والصوت والوظيفة. فوقها فهرس سريع، وزر «فهرس المشاهد» متاح دائماً.
- قائمة الصوت والمونتاج، متطلبات التصوير والتسليم، النصوص التي تحتاج اعتماد العميل، والمراجع.
- **خانات منقّطة للأصول الناقصة**: شعار حرير، واجهة التطبيق، سيارة شانجان وشعارها، صورة ماركو، اسم شركة التقسيط، البراندات، وشروط القرعة. لا يُولَّد لها بديل.

## إضافة أصول العميل الرسمية

ضع الملفات داخل المستودع (مثلاً `assets/client/`) ثم اكتب مساراتها في `config.js`:

```js
window.STORYBOARD_ASSETS = {
  harirLogo:   'assets/client/harir-logo.png',
  carImage:    'assets/client/changan.jpg',
  ...
};
```

لا حاجة لإعادة البناء؛ الخانة تمتلئ بالصورة تلقائياً.

## البنية

```
index.html            الصفحة النهائية (CSS و JS والخطوط مضمّنة؛ تعمل من القرص أو من أي استضافة)
config.js             مسارات أصول العميل الرسمية
assets/shots/         صور اللقطات 01–29 (رسومات مرجعية من الملف)
assets/board/         إطارات اللوحة المرجعية التسعة، كل واحد على حدة
assets/location/      صورة القاعة الفعلية
assets/brand/         شعار استوديو دقيقة الأصلي، ونسخة بيضاء مفرّغة منه، وفتحة العدسة
assets/fonts/         Alexandria و IBM Plex Sans Arabic (مرخّصة OFL)
src/content.json      كل نصوص العرض منقولة من الـPDF (المصدر الوحيد للمحتوى)
src/styles.css        التصميم
src/app.js            التفاعل (انترو، مكبّر، فهرس، معاينة الإيقاع، فلتر الملابس)
src/build.mjs         يولّد index.html من الملفات أعلاه
src/verify.cjs        فحص آلي للصور والحوار والروابط والتفاعل والتجاوب
```

## التعديل والبناء

```bash
# بعد تعديل src/content.json أو src/styles.css أو src/app.js
node src/build.mjs

# فحص شامل (يحتاج Playwright + Chromium)
node src/verify.cjs
```

يرفض `build.mjs` البناء إذا نقصت لقطة، أو تكررت صورة بين لقطتين، أو غاب ملف صورة.

## ملاحظات أمانة المحتوى

- صور اللقطات رسومات مرجعية للتكوين واللبس والموقع فقط، وليست صوراً للممثلات أو للسيارة أو لواجهة حرير النهائية. هذا مكتوب في الصفحة.
- في الـPDF كانت اللقطات 05/07 و06/08 و10/12 تستعمل الصورة نفسها، وبعض الصور مزاحة عن لقطاتها. في `src/content.json` يحمل كل عنصر `imageSource` (مصدر الصورة المستعملة) و`pdfImage` (الصورة التي وضعها الـPDF تحت الرقم نفسه) للمراجعة.
- `[السنة]` في نص الشاشة الختامي تبقى خانة ظاهرة حتى تُعتمد.
